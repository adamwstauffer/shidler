# International Finance and Securities Sample

This sample workspace provides a lightweight structure for organizing course project prompts, documentation, models, data, and analysis artifacts.

## Directory map

- `prompt-log.md` — running record of AI prompts, responses, assumptions, and follow-up actions.
- `docs/` — project documentation, including decisions, specifications, plans, and reusable templates.
- `models/` — model templates and completed builds.
- `data/` — source data, cleaned data, and supporting data notes.
- `analysis/` — analysis notebooks, scripts, exhibits, and interpretation notes.
